# STM32F103 小车 WS2812 跑马灯

基于串口参考工程整理的独立 Keil 工程。上电后，车头和车尾的 6 颗 WS2812 会同步显示白色单点往返跑马灯；串口 1（PA9/PA10，115200 baud）会在启动时输出一条状态信息。

## 硬件对应关系

| 原理图网络 | STM32F103C8T6 引脚 | LED 数量 |
| --- | --- | --- |
| `FR-WS2812` | PC13 | 前排 6 颗 |
| `BA-WS2812` | PC14 | 后排 6 颗 |

原理图的两条 WS2812 灯链均由 5 V 供电；请保持小车电源与下载器共地。

## 使用方法

1. 在 Keil MDK 中打开 `USER/ws2812_running_light.uvprojx`。
2. 选择 STM32F103C8T6 目标并编译、下载。
3. 复位小车，即可观察前后两排同步往返闪烁。

跑马速度由 `QST_HARDWARE/colorful_led/colorful_led.c` 中的 `delay_ms(120U)` 控制；数值越小，移动越快。

## 说明

- LED 驱动在发送 WS2812 数据时短暂关闭中断，避免串口中断改变时序。
- WS2812 使用 GRB 字节顺序，发送时序按参考工程的 72 MHz 设置。
- `OBJ/`、`Listings/` 和 Keil 用户界面配置均不包含在本项目中。
